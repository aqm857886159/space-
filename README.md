## 招股书中的关键信息

- **9,600+** 颗运行中的 Starlink 卫星
- **约 75%** 的全球在轨可机动卫星份额
- **约 1,030 万** Starlink 全球用户
- **164** 个国家和地区覆盖
- **2025 年 164 次发射**
- 主要火箭与航天器：**Falcon 9、Falcon Heavy、Starship、Dragon**
- 主要产品与服务：**Starlink、Starshield、发射服务、载人航天、货运任务**

以上数字来自招股书披露，建议在引用前用英文原文再次核对。

## 为什么值得读

![SpaceX multiplanetary mission](covers/spacex-multiplanetary-mission.jpg)

SpaceX 在这份文件里第一次用上市文件的方式系统说明自己：它不只是火箭公司，也不只是卫星互联网公司，而是在把发射、卫星、终端、国防、载人航天和火星任务放进同一个长期系统里。

这份文件的价值不只在于 IPO 本身，还在于它提供了一个窗口：你可以看到一家使命驱动型硬科技公司如何把愿景、工程、资本开支、收入结构、监管风险和长期路线图写进同一份正式文件。
